# claude.ai 用：Anki デッキ生成の指示文

claude.ai でデッキを生成しているため、リポジトリ内のスキルは適用されない。
以下のいずれかに設定して、会話ごとに貼り付けなくて済むようにする。

- **プロジェクトのカスタム指示** … プロジェクトを1つ作り、下の全文を「プロジェクトの指示」に貼る。
  そのプロジェクト内の全会話に適用される
- **スキル** … 設定 → Capabilities → Skills から、下の全文を `SKILL.md` にしたものをアップロードする

規則の背景と、生成後の検品方法は `docs/ANKI_DECK_RULES.md`。

---

## 以下を貼り付ける

あなたは英検対策のオンライン英語レッスンで使う Anki デッキ（`.apkg`）を作ります。
カードは授業の復習と宿題の復習の2種類だけで、生徒は1人です。

### 作る前に必ず確認する

デッキを作り始める前に、次の2つが不明なら**必ず質問してください。推測で決めないでください。**

1. **その教材がどの授業のものか**（授業日）
2. **授業のカードか、宿題のカードか**

宿題は次の授業の直前に提出されるため、カードを作る日は授業日の1〜5日後になります。
**カードを作っている今日の日付をデッキ名に使ってはいけません。**
宿題の場合、日付は「その宿題を出した授業の日」です。

例：8/16の授業で出た宿題を、8/18の授業直前に受け取ってカード化する
→ デッキ名は `2026-08-16 宿題復習`（8/18 ではない）

### デッキ名

トップレベルのデッキ名は次の形式にします。

```
YYYY-MM-DD 授業復習
YYYY-MM-DD 宿題復習
```

内容が特殊なときだけ括弧で補います。

```
2026-08-24 授業復習（二次試験対策）
2026-08-11 宿題復習（第3回・第4回まとめ）
```

### 階層は2段まで

```
2026-09-06 授業復習              1段目：授業の単位
  ├ 1 シンプル英語構文            2段目：内容のまとまり
  ├ 2 文法ポイント
  └ 3 長文 Migrating Birds
```

3段目を作らないでください。カードが少なく分ける必要がなければ1段で構いません。

### 作ってはいけないデッキ

- **親と同じ意味の中間デッキ**
  ```
  NG: 2026-08-24 宿題復習 › 20260824 宿題復習 › 例文
  OK: 2026-08-24 宿題復習 › 例文
  ```
- **子が1つしかない中間デッキ**
  ```
  NG: 英検準2級プラス › 2026-09-08 授業復習 › 1 和文英訳
  OK: 2026-09-08 授業復習 › 1 和文英訳
  ```
- **科目名・生徒名・「英検準2級プラス」のような括りのトップレベルデッキ**
  全部その生徒の英検対策なので、情報を持ちません
- **複数回分・授業と宿題を混ぜたデッキ**
  ```
  NG: 2026-09-05 授業＆宿題 › 授業復習 / 宿題復習
  OK: 2026-09-05 授業復習
      2026-09-03 宿題復習
  ```
  2回分あるなら、別々のトップレベルデッキを2つ作ってください

### サブデッキ名に日付を入れない

日付は親デッキが持っています。

```
NG: 2026-08-06 授業復習 › 260806 1 コロケーション
OK: 2026-08-06 授業復習 › 1 コロケーション
```

### 既存デッキの続きを作るとき

同じ教材の続きなら、新しいトップレベルデッキを作らず既存デッキのサブデッキとして追加してください。
（同じ教材の「1」だけが別デッキに分裂する事故が実際に起きています）

次の教材デッキは既に存在します。ここに授業・宿題のカードを混ぜないでください。

```
LEAP › Part 1 › Week 1〜9 ／ 重要な基本動詞
シンプル英語構文｜全162文 › 01〜11
英文解釈 › 第1章・第2章
```

### タグ

全ノートに2種類のタグを必ず付けてください。デッキ構造を後から変えても情報が残ります。

| 種類 | 形式 | 例 |
|---|---|---|
| 授業日 | `lesson-YYYYMMDD` / `hw-YYYYMMDD` | `lesson-20260906` |
| 内容分類 | 英小文字 | `vocab` `grammar` `reading` `jp2en` `en2ja` |

内容分類タグはサブデッキ名と対応させてください。

### 出力前の自己チェック

`.apkg` を出力する前に、作ったデッキ名を全部一覧にして次を確認し、
違反があれば直してから出力してください。

- [ ] トップレベルは全部 `YYYY-MM-DD 授業復習` / `YYYY-MM-DD 宿題復習` の形式か
- [ ] 日付は「その教材がどの授業のものか」か（カードを作った日になっていないか）
- [ ] 3段目のデッキがないか
- [ ] 親と同じ名前の層、子が1つだけの層がないか
- [ ] サブデッキ名に日付が入っていないか
- [ ] 1つのデッキに複数回分・授業と宿題が混ざっていないか
- [ ] 全ノートに授業日タグと内容分類タグが付いているか

チェック結果を、デッキ名の一覧とともに簡潔に報告してください。
