# Anki デッキ命名規則

生徒に配布する Anki デッキ（`.apkg`）を AI に生成させるときの仕様。
生成のたびにこのファイルの「AI に渡す指示」の節をそのまま貼り付ける。

生成物の検品は `scripts/anki/check_deck.py` で行う（`docs/ANKI_DECK_CHECK.md` 参照）。

## なぜ規則が必要か

AI に任せて生成すると、次の問題が繰り返し発生した。

- 親と同じ名前の中間デッキが挟まる（`260824 宿題復習 › 20260824 宿題復習 › 例文`）
- 日付の表記が生成のたびに変わる（`260806_` `260816 ` `20260820` `2026-08-10`）
- 1つのデッキに複数回分の授業が同居する（`260827と0901 Souma`）
- 同じ教材が2つの親デッキに分裂する
- 宿題デッキの日付が「カードを作った日」になり、「どの授業の宿題か」が失われる

いずれもデッキ構造だけの問題で学習履歴には影響しないが、
デッキ一覧が読めなくなり、生徒がどれを開けばよいか分からなくなる。

## 規則

### 1. デッキ名は「授業日 + 種別」

```
YYYY-MM-DD 授業復習
YYYY-MM-DD 宿題復習
```

内容が特殊な場合のみ括弧で補う。

```
2026-08-24 授業復習（二次試験対策）
2026-08-11 宿題復習（第3回・第4回まとめ）
```

### 2. 日付は「その教材がどの授業のものか」

カードを作成した日ではない。

- **授業カード** … その授業が行われた日
- **宿題カード** … その宿題を**出した授業**の日

宿題は次の授業の直前に提出されるため、カードを作る日は授業日の1〜5日後になる。
この作成日をデッキ名に使ってはいけない。

```
8/16 授業 → 宿題を出す
8/18 授業の直前に宿題を受け取る → 8/18 にカード化
　　→ デッキ名は「2026-08-16 宿題復習」（8/18 ではない）
```

### 3. 階層は2段まで

```
2026-09-06 授業復習              ← 1段目：授業の単位
  ├ 1 シンプル英語構文            ← 2段目：内容のまとまり
  ├ 2 文法ポイント
  └ 3 長文 Migrating Birds
```

3段目を作らない。カードが少なく分ける必要がなければ1段でよい。

### 4. 中間デッキを作らない

親と同じ意味の層、子が1つしかない層は作らない。

```
NG: 260824 宿題復習 › 20260824 宿題復習 › 例文
OK: 2026-08-24 宿題復習 › 例文

NG: 英検準2級プラス › 2026-09-08 授業復習 › 1 和文英訳
OK: 2026-09-08 授業復習 › 1 和文英訳
```

科目名・生徒名・「英検準2級プラス」のような括りのデッキを新規に作らない。
このコレクションは全部その生徒の英検対策なので、情報を持たない。

### 5. 1デッキ＝1回分

複数回分・授業と宿題を1つのデッキにまとめない。分けて別のトップレベルデッキにする。

```
NG: 260905 授業＆宿題 › 260905 授業復習 / 260905 宿題復習（比較…）
OK: 2026-09-05 授業復習
    2026-09-03 宿題復習
```

### 6. サブデッキ名に日付を入れない

日付は親が持っている。

```
NG: 2026-08-06 授業復習 › 260806 1 コロケーション
OK: 2026-08-06 授業復習 › 1 コロケーション
```

### 7. 既存デッキと同じ教材なら同じデッキに入れる

同じ教材の続きを作るときは、新しいトップレベルデッキを作らず既存デッキのサブデッキとして追加する。
（`英検準2級プラス二次試験 第4回` の「1」だけが別デッキに分裂した事故が実際に起きている）

### 8. 教材デッキは触らない

`LEAP` `シンプル英語構文｜全162文` `英文解釈` は構造に意味があるので、
授業・宿題のカードを混ぜない。

### 9. タグを必ず付ける

デッキを畳んでも情報が残るよう、全ノートに以下を付ける。

| タグ | 例 | 用途 |
|---|---|---|
| 授業日 | `lesson-20260906` / `hw-20260906` | 授業か宿題か＋その授業日 |
| 内容分類 | `vocab` `grammar` `reading` `jp2en` | サブデッキ名に対応 |

## AI に渡す指示

デッキ生成を依頼するとき、以下をそのまま貼り付ける。

---

Anki デッキを作るとき、次の命名規則に必ず従ってください。

1. トップレベルのデッキ名は `YYYY-MM-DD 授業復習` または `YYYY-MM-DD 宿題復習` の形式にする。内容が特殊なときだけ `2026-08-24 授業復習（二次試験対策）` のように括弧で補う
2. 日付は「その教材がどの授業のものか」を表す。授業カードはその授業日、宿題カードは**その宿題を出した授業の日**。カードを作成した日は使わない
3. 階層は**2段まで**。`授業デッキ › 内容のまとまり` で終える。3段目を作らない
4. 親と同じ名前の中間デッキ、子が1つしかない中間デッキを作らない
5. 科目名・生徒名・「英検準2級プラス」のような括りのトップレベルデッキを新設しない
6. 1つのデッキに複数回分の授業や、授業と宿題を混ぜない。分けて別デッキにする
7. サブデッキ名に日付を入れない（日付は親デッキが持っている）
8. 既存の教材の続きを作る場合は、新しいトップレベルデッキを作らず既存デッキのサブデッキにする
9. 全ノートにタグを付ける。授業日タグ（`lesson-YYYYMMDD` または `hw-YYYYMMDD`）と内容分類タグ（`vocab` `grammar` `reading` など）の2種類

出力前に、作ったデッキ名を一覧にして上の1〜9に違反していないか自己チェックし、
違反があれば直してから出力してください。

---

## 生成後の確認

```bash
python3 scripts/anki/check_deck.py 生成された.apkg
```

違反があれば一覧で表示される。機械的に直せるものは `--fix` で修正版を出力できる。

```bash
python3 scripts/anki/check_deck.py 生成された.apkg --fix 修正版.apkg
```

`--fix` が直すのは階層と表記だけで、ノート・カードのスケジュール・レビュー履歴には触れない。
「どの授業の宿題か」のような判断が必要な部分は警告のみで、手で直す。
